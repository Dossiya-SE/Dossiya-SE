### Release approach

Each repository must regenerate modified source-owned figures from its code and pass local CI, whitespace/palette/contrast and visual screenshot review. A policy table is **not** proof that all 18 repositories comply. Do not infer a PR or status from registry membership.

1. Fix source assets and stable semantic registers.
2. Verify mathematical labels, data values, state classifications, graph topology and scientific legends unchanged.
3. Verify 100% white figure/panel interiors, deterministic source-output agreement where generators exist.
4. Use 3:1 essential graphical and 4.5:1 ordinary text contrast checks; permit nonessential low-contrast accents only with labels/outlines.
5. Run regression and independent visual checks, preserve evidence and archive integrity, then merge individual PRs only if gates pass.

**Exception policy:** Never automatically migrate the finance palette to Deck3 or the ASU palette to other repositories. Do not silently rewrite immutable archived notebooks or Canva/PNG references.
