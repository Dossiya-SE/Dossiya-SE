# Research Visual Semantics V1

| Object | Canonical visual grammar |
|---|---|
| Physical component | typed node / bounded component |
| Physical connection | solid edge |
| Cross-infrastructure interface | Light Sky Blue typed interface object |
| Information dependency | blue dashed edge |
| Organizational dependency | magenta dotted/dashed edge |
| State | point/vector/state marker |
| Viable region | bounded green-tinted region |
| Critical boundary | red boundary plus dash/label |
| Projection/resilience margin | Light Sky Blue segment + mathematical label |
| Uncertainty | interval, band, distribution or ensemble |
| Evidence state | explicit S/D/M/C/V/E/H/T token |

Visual proximity, thickness, brightness, area and speed must not imply importance, causality, confidence, probability or validity unless the encoding is defined and sourced.

For Power ↔ Transportation work: power red, transportation green, shared interface Light Sky Blue, state/geometry violet, viable green, critical red, information blue, organization magenta.

For quantitative finance: observed data blue; model/latent state violet; validated numerical condition green; risk/constraint breach red; decision/highlight Light Sky Blue; uncertainty via explicit intervals/bands/ensembles. Profit/loss must not rely on green/red alone.
