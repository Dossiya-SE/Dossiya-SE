## Profile message

The professional profile should communicate this principle:

> Real systems are translated into explicit variables, objectives, constraints, and parameters; mathematical algorithms produce candidate solutions; independent feasibility/optimality checks and uncertainty/sensitivity analysis bound what can responsibly be claimed or decided.

This framing integrates deterministic operations research, Bayesian sequential optimization, infrastructure systems, and the existing evidence-state architecture without presenting coursework as original research.
