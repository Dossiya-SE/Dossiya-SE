# Profile Improvement Request Ledger

Every material profile-improvement instruction is recorded here before or alongside implementation.

## Naming convention

```text
YYYY-MM-DD_NNN_short-slug.md
```

## Status vocabulary

- `PROPOSED` — request recorded, not yet implemented;
- `IMPLEMENTED` — repository changes created;
- `VERIFIED` — relevant content/render/evidence checks passed;
- `RELEASED` — merged/published on the intended public surface;
- `REJECTED` — not implemented because of evidence, safety, duplication or user decision.
