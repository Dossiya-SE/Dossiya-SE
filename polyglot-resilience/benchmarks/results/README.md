# Benchmark Results

No cross-language performance ranking is published yet.

This is intentional. The benchmark layer opens only after an implementation has passed the conformance and numerical-validation gates defined in `../../VALIDATION_STANDARD.md` and `../../BENCHMARK_PROTOCOL.md`.

When benchmark evidence is added, this directory should contain:

- raw machine-readable measurements;
- environment/provenance manifests;
- summary tables;
- plots generated from raw measurements;
- explicit implementation/profile identifiers;
- numerical-error checks alongside performance metrics.

A performance result without corresponding correctness evidence is inadmissible in this atlas.
