## Release boundary

This production version deliberately promotes the **decision architecture, source anchors, executable benchmark certificates, and professional visual layer** without bulk-copying course formulas into the canonical formula registry.

Course-derived mathematics remains source-grounded instructional mathematics `[S]`. Computed benchmark results are `[C]`; certificate/residual checks are `[V]` only for their implemented instances. No solver result or passing software test is represented as empirical validation `[E]` of a real-world system.

The implementation remains fail-closed: a future change to the lab, source anchors, knowledge graph, V6 decision visual, or root integration must satisfy `optimization-decision-audit` before promotion.
