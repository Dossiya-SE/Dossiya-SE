# Evidence-Led Action-Verb Writing Skill

**Status:** Reusable writing reference, not a fact-verification service or automatic installation in every ChatGPT conversation.

## Governing principle

**Choose the strongest action verb that the available evidence justifies, not the strongest-sounding verb.**

The seven user-authorized rules are retained in the [full skill](SKILL.md), with scientific evidence-level gates, attribution safeguards, protected-text rules, and verification checks.

## Files

- [SKILL.md](SKILL.md): Complete method, evidence-maturity levels, verb gates, scientific integrity, writing by genre and final QA.
- [ACTION_VERB_BANK.md](references/ACTION_VERB_BANK.md): Curated verb families for science, computation, collaboration, communication, leadership, teaching, engineering and outcomes.
- [TEMPLATES_AND_EXAMPLES.md](references/TEMPLATES_AND_EXAMPLES.md): Copy-ready patterns and qualified examples for thesis, CV, SOP, engineering, leadership and README content.
